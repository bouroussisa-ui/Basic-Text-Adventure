## Running It Locally
If you want to run the source code on your own computer:

1. Clone this repository:
   ```bash
   git clone https://github.com/bouroussisa-ui/Basic-Text-Adventure.git
   ```
2. Navigate into the folder:
   ```bash
   cd Basic-Text-Adventure
   ```
3. Run the game:
   ```bash
   python game.py
   ```
